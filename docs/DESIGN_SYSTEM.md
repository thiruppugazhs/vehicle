# FleetPulse Light-Theme Design System

## Color Palette Tokens
- Background: `#FFFFFF` (Primary Surface), `#F8FAFC` (Canvas)
- Borders: `#E2E8F0` (Subtle Slate)
- Typography: `#0F172A` (Heading), `#334155` (Body), `#64748B` (Muted)
- Accent: `#D97706` / `#F59E0B` (Industrial Warm Amber)

## Semantic Status Tokens
- Active / Valid: `#10B981` (Emerald)
- Due / Warning: `#F59E0B` (Amber)
- Overdue / Critical: `#EF4444` (Rose / Red)
- Under Maintenance: `#3B82F6` (Blue)

## Accessibility
All text meets WCAG AA standards with contrast ratios exceeding 4.5:1 on light backgrounds.

## Grid & Breakpoints
- Mobile: `< 640px` (Single column cards, slide-out navigation)
- Tablet: `640px - 1024px` (2-column layout)
- Desktop: `> 1024px` (Fixed enterprise sidebar, high-density tables)
